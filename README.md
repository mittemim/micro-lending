# Lending

Разрабатываем одностраничный лендинг на **Next.js, React и TypeScript** с **npm** в качестве менеджера пакетов.

На странице будут секции Hero, «Плюсы», «Вопросы» и «Форма». Якорная навигация позволит переходить к нужной секции.

Форма содержит поля «Имя», Email и «Описание задачи». Состояние формы хранится на клиенте: пустые и некорректные поля показывают понятные сообщения об ошибках, а после корректного заполнения появляется сообщение об успехе.

## Запуск

После реализации проекта и установки зависимостей:

```bash
npm run dev
```

Открыть страницу в браузере по адресу, указанному в терминале (обычно http://localhost:3000).

## Критерии готовности

- Проект запускается командой `npm run dev`, страница открывается в браузере.
- Видны Hero, блок преимуществ «Плюсы», блок «Вопросы» и форма.
- Якорная навигация переводит к соответствующим секциям.
- Форма содержит поля «Имя», Email и «Описание задачи».
- Пустые и некорректные значения вызывают понятные ошибки.
- Корректное заполнение формы приводит к сообщению об успехе.
